📱 Learning App – Full Stack Mobile Application<br><br>
📌 Project Overview

This project is a feature-rich learning and productivity mobile application designed to help users manage courses, track progress, access AI-powered tools, and plan their study routines efficiently.
The app was developed following a 12-week structured roadmap, covering planning, development, AI integration, testing, and documentation.

The project focuses on scalable architecture, clean UI/UX, CI/CD practices, and modular development.

🚀 Features Implemented <br><br>
✅ Core Features

1) Home Dashboard : Centralized overview of user activities , Quick navigation to key modules

2) Registered Courses : Dynamic course list, Progress tracking with visual indicators

3) Resume Last Activity: Session-based continuation of learning, Smart state management

4) Weekly Updates Feed: Personalized feed of new courses and content, Backend-driven data rendering

5) Challenges & Exams: Quizzes and mock tests, Automated evaluation and result tracking

🤖 AI-Powered Features

1) AI Assistant: Conversational chatbot for guided learning, Backend-integrated conversational flows

2) AI Short Answer Tool: Instant definitions and summaries, Optimized for quick learning support

📅 Productivity Tools

1) Smart Timetable Planner: Custom study schedules,Persistent backend storage

2) User Profile & Analytics:Profile management,Visual performance analytics and insights
