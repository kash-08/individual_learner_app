📱 Learning App – Full Stack Mobile Application<br><br>
📌 Project Overview

This project is a feature-rich learning and productivity mobile application designed to help users manage courses, track progress, access AI-powered tools, and plan their study routines efficiently.
The app was developed following a 12-week structured roadmap, covering planning, development, AI integration, testing, and documentation.

The project focuses on scalable architecture, clean UI/UX, CI/CD practices, and modular development.
